# AI 报告新闻引用改造 — 端到端验证报告

- 日期：2026-10-17
- 涉及文件：`app/services/analyze.py`
- 验证方式：真实端到端 `analyze` 调用（单次运行），非 mock。

---

## 1. 背景与目标

对 AI 生成报告的“新闻引用”能力做了两处改造，本次验证的目标是确认两处改动在真实调用链路上生效：

1. **新闻格式化带来源链接**：`build_local_context` 中 `_fmt_news` 对每条本地新闻追加 ` | 来源：<url>`。
2. **SYSTEM_PROMPT 强制“参考资料”小节**：在系统提示词中要求报告末尾必须有“参考资料”小节，逐条列出引用的新闻/资讯原始链接（标题 + 链接），并要求“若某条结论引用了新闻，请务必让读者能通过该链接找到来源”。

判断标准：调用真实 `analyze` 后，返回的 `analysis` 文本中——
- (A) 是否包含“参考资料”小节；
- (B) 该小节内（及全文）是否出现 `http://` 或 `https://` 链接；
- (C) 链接是否能对应到本地新闻 / 联网搜索的原始 url。

---

## 2. 验证方法与脚本

创建临时脚本 `_verify_run.py`（用后即删），构造一次真实调用：

- 标的：`600519`（贵州茅台）
- 参数：`use_search=True`、`top_k=3`
- 流程：构建本地上下文 → 联网搜索 → 组装 prompt → 调用内部网络 LLM 端点 → 对返回的 `analysis` 文本做 ASCII 关键字检查，避免终端 GBK 编码干扰中文显示。

检查项输出（均为 ASCII，清晰可读）：
- `analysis` 长度、是否含 `参考资料`、出现的 `http(s)` 链接数量、链接列表抽样。

| 检查项 | 结果 | 说明 |

## 4. 结论

两处改动均已在真实调用链路上得到验证：

- 新闻目标地址成功进入 prompt 与最终报告；
- LLM 已按 SYSTEM_PROMPT 要求输出带原始链接的“参考资料”小节，读者可据此回溯新闻来源。

改造满足预期，可进入后续发布环节。
